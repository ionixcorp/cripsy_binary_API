API moderna (Rust) para brókers de opciones binarias
Comprobando instalación…

La API todavía no está instalada en este equipo. La instalación es guiada en PowerShell y nada se instala sin tu aprobación.

  1. Abre una terminal (PowerShell 7 recomendado) en la raíz del proyecto.
  2. Ejecuta .\installation\install.ps1
  3. El instalador verificará el entorno (Rust, cargo, git), te preguntará antes de instalar lo que falte, creará tu .env, compilará la librería en sus dos variantes, generará esta documentación y ejecutará una prueba de conexión de solo lectura si la apruebas.
  4. Al terminar, recarga esta página: la documentación se abrirá automáticamente.
Ver guía de instalación Guía de uso y reglas
Un navegador no puede instalar software: la instalación la realiza el script real de PowerShell, con aprobación en cada paso. Esta página solo detecta el resultado. Si tu equipo quiere consumir la API desde otro proyecto, empieza por el README.md.
